# Outdoors

This folder is for finding V0-17 boulder problems outdoors (primarily Grampians, other regions may be added later), and for planning weekend camping trips there.

- Home base: Melbourne. Trips are day drives to the Grampians (or other regions as added).
- Grade range of interest: V0-17.
- Primary beta source: theCrag.com.
- Camping is a mix of car camping and hike-in — don't assume gear needs based on one style only.

## Git

Commit changes as you make them, with a clear message describing what changed. Don't batch unrelated changes into one commit.
